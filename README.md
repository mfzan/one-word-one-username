One word, one username, one reward: this entry sends a single word — our own make.fun username, `mfzan`. Five letters, no padding, no gimmick: a short gamertag-style handle that sounds like a person with a story behind it.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

The program writes exactly `mfzan` (5 bytes, no trailing newline) to `/output/entry.txt`, with the file world-readable (0644) and its folder traversable (0755), so the grader can collect it.
